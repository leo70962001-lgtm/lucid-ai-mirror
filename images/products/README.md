# 商品照

把**去背**商品照放進 `images/products/`，用商品 id 命名即可，不需要改任何程式碼：

```
images/products/L204.png    ← #204 蜜楓棕
images/products/L118.png
images/products/E01.webp    ← 副檔名 png / webp / jpg / jpeg 都可以
images/products/C01.png
```

主程式會自動偵測並改用照片；沒有對應檔案時，會退回用 CSS 畫的商品圖，
所以缺圖不會開天窗，可以一張一張慢慢補。

id 對照表看 `../js/products.js`。

## 放進來之後一定要跑這個

<http://localhost:5173/_ingest.html>

它會從每張照片抽出主色，跟 `products.js` 裡宣告的 `color` 比對色差（ΔE）：

| ΔE | 判定 |
|---|---|
| < 5 | 一致 |
| 5–10 | 看得出差異 |
| ≥ 10 | 明顯不符 |

**為什麼這件事重要**：Step 3 顧客看到的是照片，Step 4 的 AR 渲染用的是 `color` 色值。
兩者不一致的話，顧客會覺得「AR 的顏色跟商品圖不一樣」，整套體驗的可信度會當場崩掉。

工具會直接產生可貼回 `products.js` 的修正值。但注意：**照片只是比手選色碼更接近實品，
不是權威來源**。正式上線前應該用色差儀量測實品在標準光源（D65）下的 Lab 值。

## 拍攝建議

- 純白或純色背景，去背存成 PNG（帶 alpha）
- 直幅，商品置中，四周留白約 10%
- 避免有色光源與有色反光板 —— 打光的顏色會被算進主色
- 同一批商品用同一組光源與白平衡，否則色差比對會失去意義
